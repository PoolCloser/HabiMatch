# HabiMatch Sprint 2 Plan

Team HabiMatch

Project HabiMatch

Mary Tarevern, Koa Wolfe, Drake Griffin, James Yeh, Ethan Nguyen

April 22, 2026

## Goal

Build the core roommate-matching experience for HabiMatch by implementing the compatibility scoring algorithm and a swipeable feed that lets users view, evaluate, and understand suggested roommate matches. The matching algorithm and feed are the main parts of HabiMatch, so this sprint focuses on getting that core flow working end-to-end.

## Task Listing (by User Story)

### User Story 1 (US-201): As a user, I want the app to match me based on what matters most to me as a housemate.

| Task | Time estimate |
|---|---|
| T-201: Design and implement the scoring algorithm with weights, inputs, and logic. | 6 hrs |
| Refined questionnaire: Update the questionnaire to better follow the structure outlined in the design document. | 1 hr |
| **Total for User Story 1 (US-201)** | **7 hours** |

### User Story 2 (US-202): As a user, I want a swipeable feed of suggested roommates so that I can evaluate potential matches.

| Task | Time estimate |
|---|---|
| T-202a: Build the feed API endpoint that returns a hardcoded list of mock roommate profiles. | 3 hrs |
| T-202b: Build the roommate feed UI. | 4 hrs |
| T-202c: Integrate the feed UI with the live feed API endpoint. | 2 hrs |
| **Total for User Story 2 (US-202)** | **9 hours** |

### User Story 3 (US-203): As a user, I want to see my compatibility score and a brief breakdown on a profile.

| Task | Time estimate |
|---|---|
| T-203a: Build the compatibility breakdown UI using mock score data so users can see their compatibility score and a short explanation on a roommate profile. | 4 hrs |
| **Total for User Story 3 (US-203)** | **4 hours** |

**Total planned effort for Sprint 2: 20 ideal hours**
