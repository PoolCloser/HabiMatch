## Goal

Polish the profile and browsing experience for the final release. This sprint lets users view and edit their profile and update their preferences, and makes browsing potential roommates feel natural with swipe based navigation and correct profile photos.

## Task Listing (by User Story)

User stories are listed in priority order, most important first.

### User Story 1 (US-401), Priority High: As a user, I want to view and edit my profile so that I can keep my information up to date.

| Task | Time estimate |
|---|---|
| US-401-A: Move account actions into the profile settings gear, cleaning up the profile tab by moving account level actions behind the gear icon. | 2 hrs |
| US-401-B: Add an update preferences entry point, a profile page button that sends the user back into the existing questionnaire flow. | 2 hrs |
| US-401-C: Support a questionnaire edit mode by reusing the current questionnaire for preference updates. | 3 hrs |
| US-401-D: Improve profile editing persistence so that profile info edits remain reliable. | 3 hrs |
| US-401-E: Harden the profile update endpoint with server side validation and clear error handling so edited fields are saved correctly. | 3 hrs |
| US-401-F: Add profile photo validation and storage handling, and collaborate on the default photo fix so uploads are stored and served reliably. | 3 hrs |
| **Total for User Story 1 (US-401)** | **16 hours** |

### User Story 2 (US-402), Priority Medium: As a user, I want to browse potential roommates by swiping so that finding matches feels fast and natural.

| Task | Time estimate |
|---|---|
| US-402-A: Fix the default photo selection by removing the hardwired "HA" profile picture so that each profile shows its own photo (issue #51). | 2 hrs |
| US-402-B: Add swiping instead of individual buttons, so the user swipes left or right depending on preference and swipes down to refresh (issue #52). | 4 hrs |
| US-402-C: Add a refresh endpoint that returns a fresh batch of suggested profiles when the user swipes down. | 3 hrs |
| US-402-D: Add swipe animations and visual feedback, including card tilt and like and pass overlays, to the swipe feed. | 3 hrs |
| **Total for User Story 2 (US-402)** | **12 hours** |

**Total planned effort for Sprint 4: 28 ideal hours**
